PawnIO Modules embedded in LibreHardwareMonitorLib 0.9.6
=====================================================

Component: PawnIO.Modules, official release 0.2.2
License: GNU Lesser General Public License, version 2.1 or later
SPDX: LGPL-2.1-or-later

GlimHUD redistributes the unmodified LibreHardwareMonitorLib 0.9.6 assembly.
That assembly embeds the twelve signed PawnIO module bytecode files listed
below. These module resources are separate from LibreHardwareMonitor's
MPL-2.0 core code and from the separate PawnIO kernel driver/installer.

Full license text is retained in PawnIO.Modules.LGPL-2.1.txt in this directory.
The original LibreHardwareMonitor resource README is retained verbatim as
PawnIO.Modules.Upstream-README.txt.
