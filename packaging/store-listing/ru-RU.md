# GlimHUD — черновик описания для Microsoft Store

Статус: черновик для проверки. Публикация возможна после устранения ограничений Store, описанных в `docs/microsoft-store.md`. Описание должно соответствовать финальной сборке.

## Краткое описание

Управление музыкой и показатели ПК в прозрачном оверлее рабочего стола.

## Описание

Музыка и состояние компьютера рядом с игрой. GlimHUD — компактный оверлей с настраиваемой прозрачностью и акцентным цветом.

Управляйте совместимыми медиаплеерами Windows, смотрите название трека и обложку, меняйте громкость или полностью скрывайте плеер. Используйте акцентный цвет Windows или выберите свой, настройте оверлей и переключайте интерфейс между английским и русским языками.

GlimHUD — бесплатное приложение с открытым исходным кодом под лицензией MIT.

## Возможности для проверки

- Прозрачный оверлей с настройкой внешнего вида.
- Управление системными медиасеансами, информация о треке и обложка из совместимых плееров.
- Настраиваемое изменение громкости колесом мыши в зоне плеера.
- Возможность скрыть плеер и автоматически показывать оверлей во время игры.
- Загрузка процессора и оперативной памяти.
- Английский и русский интерфейс.

Упоминания загрузки и температуры GPU, температуры CPU и FPS нужно добавить только после проверки финальной Store-сборки с обычными правами пользователя. Доступность показателей зависит от оборудования и разрешений. Совместимость с играми и режимами отображения необходимо проверить отдельно.

## До публикации

Нужны данные проверенного издателя, ссылки на поддержку, политику конфиденциальности и публичный репозиторий, реальные скриншоты приложения, список изменений и пояснения для сертификации.
