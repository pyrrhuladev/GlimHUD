# Security policy

Security fixes are made against the latest development version and latest release. Older releases may not receive backports.

Use this repository's **Security → Report a vulnerability** option when private vulnerability reporting is available. If that option is unavailable, use a contact method explicitly listed by the maintainer on their [GitHub profile](https://github.com/pyrrhuladev) to request a private reporting channel. Do not publish credentials, private data, or exploit details in a public issue.

Include the affected version, Windows version, impact, and a minimal reproduction. Share only the data needed to reproduce the issue. Do not include another application's private media metadata or a full process list unless it is essential and has been reviewed for personal information.

GlimHUD does not automatically request elevated privileges or change security settings. A portable build is currently unsigned. Download releases through this repository and compare the published SHA-256 checksum when available. A checksum detects a mismatch with the listed artifact; it is not a publisher signature.
